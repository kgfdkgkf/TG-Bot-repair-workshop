# 🛠 Telegram-бот сервиса ремонта цифровой техники

Полностью разделённый интерфейс для **пользователя / менеджера / администратора**.

## Что нового в пользовательской части
- Каталог устройств с зависимыми неисправностями.
- Для каждой неисправности отдельный список допустимых причин. Нельзя выбрать причину от другой проблемы.
- Телефон принимается только как `7XXXXXXXXXX` или `+7XXXXXXXXXX` — ровно 11 цифр, без пробелов, скобок и дефисов. Формат `8XXXXXXXXXX` отклоняется.
- Отдельный чат по каждой заявке: клиент ↔ менеджер. История хранится в SQLite.
- FAQ, услуги, профиль, история ремонтов и список чатов.

## Роли

### Пользователь
- Создание заявки через FSM из 6 шагов.
- Проверка типа данных: на шаге фото текст не ломает бота.
- Просмотр своих заявок с пагинацией.
- Получение уведомлений о смене статуса и новой цене.

### Менеджер
- Отдельная панель без функций пользователя и администратора.
- Новые / в работе / все / завершённые заявки.
- По 3 заявки на страницу.
- Карточка заявки с клиентом, проблемой, телефоном, ценой и фото.
- Смена статуса, установка цены, комментарий, сообщение клиенту.
- Повторное нажатие того же статуса не отправляет повторное уведомление.

### Администратор
- Только системная панель: дашборд, заявки, Excel-отчёт, менеджеры, назначение менеджера.
- Нет кнопок «Создать заявку» и «Мои заявки».
- Назначение менеджера по Telegram ID или @username с подтверждением.
- Снятие прав менеджера.
- Фильтрация заявок по статусам.
- Excel-отчёт за выбранный период.

## Запуск

```bash
cp .env.example .env
# заполнить .env
pip install -r requirements.txt
python -m app.main
```

## Docker

```bash
docker compose up -d --build
```

SQLite хранится в `data/repair_bot.db`.

## Чат клиент ↔ менеджер
После создания заявки пользователь открывает её и нажимает «💬 Открыть чат». Менеджер открывает «💬 Чаты» или чат из карточки заявки. Сообщения сохраняются в таблице `chat_messages` и доставляются второй стороне.

## Важно про менеджера

Администратор сначала назначает пользователю роль менеджера. После этого менеджер входит через `/login` с `MANAGER_PASSWORD`.

Администратор определяется через `ADMIN_IDS` и `ADMIN_PASSWORD`.

## Что нового в этой версии

- Приветствие «Добро пожаловать в мастерскую у CYхарика» для клиента.
- Администратор может блокировать и разблокировать пользователей; админов заблокировать нельзя.
- Защита от частого спама: ограничение слишком частых действий на одного пользователя.
- Строгая проверка телефона: только `7XXXXXXXXXX` или `+7XXXXXXXXXX`.
- Пользовательские свободные поля проверяются на осмысленный ввод, случайные наборы символов отклоняются.
- Для сборных ПК вместо фиктивной «модели» есть конфигурация и отдельный выбор комплектующего: CPU, GPU, RAM, SSD/HDD, PSU, материнская плата, охлаждение, монитор, периферия. Для каждого узла — свои проблемы и причины.
- Для остальных типов техники причина берётся только из списка, связанного с выбранной неисправностью.
- Добавлен раздел «💡 Советы».
